# FastAPI Backend Project

## 📌 Description

This project is a beginner-friendly REST API built using **FastAPI**, a modern Python framework for building fast and efficient backend applications.

The project was created to learn backend development concepts such as API endpoints, HTTP requests, JSON responses, and API documentation.

---

## 🚀 Features

- Built with FastAPI
- RESTful API endpoints
- Automatic interactive API documentation
- JSON responses
- Lightweight and high-performance backend

---

## 🛠️ Technologies Used

- Python 3
- FastAPI
- Uvicorn

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Summer-Projects-2026.git
```

Navigate to the project

```bash
cd first-api
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

Start the server

```bash
uvicorn main:app --reload
```

---

## 🌐 API Documentation

After running the project, open:

Swagger UI

```
http://127.0.0.1:8000/docs
```

ReDoc

```
http://127.0.0.1:8000/redoc
```
